# Public Media Assets

This directory is intentionally empty during the foundation phase.

## Before public launch

Add only approved assets:

- final Academy crest/logo,
- compact favicon derived from the approved identity,
- 4–7 approved training photographs,
- optional Open Graph/share image.

## Important

The current `/favicon.svg` and the CSS `.brand-mark` are **development placeholders**, not final Academy heraldry.

Do not treat them as canonical Academy marks.
